# Lumina

**Play: https://jonathanmathews449-stack.github.io/lumina-tide/**

Lumina is a dependency-free canvas arcade game built for GitHub Pages. Guide a
living spark through a one-minute bioluminescent current, collect light motes,
thread rifts, escape seekers, and release charged pulses.

Boost is the loop: holding Shift burns a metered reserve roughly three times faster
than it recovers, and grazing an ink bloom without touching it pays that reserve back.
The dive deepens every fourteen seconds to a cap of five. Depth two opens moving
rifts: pass through their centre to extend the chain and restore boost. Depth three
wakes seekers that bend toward the player; boosting disrupts their lock, surviving
their pursuit restores boost, and a charged pulse can clear them with the ink.

## Controls

- Pointer or touch: steer toward the target
- WASD or arrow keys: directional movement
- Shift, or the Boost button: burn the boost reserve for speed
- Space: release a fully charged pulse
- Escape: pause or resume

## Features

- Responsive high-DPI canvas rendering
- Particle systems, procedural currents, and dynamic lighting
- Progressive depth, score chains, rift bonuses, pursuing seekers, grazing, energy, boost, pulse, and a timed run
- Optional synthesized sound effects with Web Audio
- Local high-score persistence
- Keyboard, pointer, and touch controls
- Reduced-motion support
