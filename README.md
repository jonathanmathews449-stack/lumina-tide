# Lumina Tide

Lumina Tide is a dependency-free canvas arcade game built for GitHub Pages. Guide a living spark through a bioluminescent current, collect light motes, avoid ink blooms, build multipliers, and release charged pulses.

## Controls

- Pointer or touch: steer toward the target
- WASD or arrow keys: directional movement
- Space: release a fully charged pulse
- Escape: pause or resume

## Features

- Responsive high-DPI canvas rendering
- Particle systems, procedural currents, and dynamic lighting
- Progressive difficulty, score chains, energy, pulse ability, and a timed run
- Optional synthesized sound effects with Web Audio
- Local high-score persistence
- Keyboard, pointer, and touch controls
- Reduced-motion support
