# Lumina Tide

**Play: https://jonathanmathews449-stack.github.io/lumina-tide/**

Lumina Tide is a dependency-free canvas arcade game built for GitHub Pages. Guide a
living spark through a bioluminescent current, collect light motes, avoid ink blooms,
build chains, and release charged pulses.

Boost is the loop: holding Shift burns a metered reserve roughly three times faster
than it recovers, and grazing an ink bloom without touching it pays that reserve back.
The dive deepens every fourteen seconds to a cap of five, and the ink comes faster
with it.

## Controls

- Pointer or touch: steer toward the target
- WASD or arrow keys: directional movement
- Shift, or the Boost button: burn the boost reserve for speed
- Space: release a fully charged pulse
- Escape: pause or resume

## Features

- Responsive high-DPI canvas rendering
- Particle systems, procedural currents, and dynamic lighting
- Progressive depth, score chains, grazing bonuses, energy, boost, pulse, and a timed run
- Optional synthesized sound effects with Web Audio
- Local high-score persistence
- Keyboard, pointer, and touch controls
- Reduced-motion support
